# 🚀 Agilizia_AI - App de Demonstração Interativo

## 📱 **APRESENTAÇÃO PROFISSIONAL DO PROJETO**

Este é um aplicativo de demonstração interativo criado para apresentar o sistema Agilizia_AI de forma profissional e envolvente.

## ✨ **FUNCIONALIDADES DO APP**

### 🎯 **Demonstração Interativa**
- **Scanner Inteligente** - Simulação do reconhecimento de produtos
- **Carrinho Digital** - Gestão de itens com cálculos automáticos
- **Dashboard ESG** - Scores de sustentabilidade em tempo real
- **Pagamentos** - Processamento multi-método (PIX, Cartão, Dinheiro)

### 📊 **Calculadora de ROI**
- Inputs personalizáveis (clientes, tempo, abandono)
- Cálculos automáticos de ROI
- Métricas de performance em tempo real

### 🎨 **Design Profissional**
- Interface moderna e responsiva
- Animações suaves e interativas
- Mockups de dispositivos móveis
- Gradientes e efeitos visuais

## 🚀 **COMO USAR**

### **1. Abrir o App**
```bash
# Navegue até a pasta do demo
cd docs/demo-app

# Abra o arquivo index.html no navegador
# Ou use um servidor local:
python -m http.server 8000
# Acesse: http://localhost:8000
```

### **2. Navegação**
- **Demo** - Demonstração interativa das funcionalidades
- **Funcionalidades** - Cards com detalhes das features
- **ROI** - Calculadora de retorno sobre investimento
- **Contato** - Formulário para agendamento de demos

### **3. Interações**
- **Clique nos botões** para alternar entre demos
- **Ajuste os valores** na calculadora de ROI
- **Preencha o formulário** para solicitar demonstração
- **Navegue com scroll** suave entre seções
