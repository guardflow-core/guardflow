## 🚀 **COMO ATIVAR O GITHUB PAGES:**

### **Passo 1: Acessar Configurações**
1. Vá para: https://github.com/SH1W4/guardflow-saas
2. Clique em **"Settings"** (Configurações)
3. Role até **"Pages"** no menu lateral

### **Passo 2: Configurar Source**
1. Em **"Source"**, selecione: **"Deploy from a branch"**
2. Em **"Branch"**, selecione: **"main"**
3. Em **"Folder"**, selecione: **"/docs"**
4. Clique em **"Save"**

### **Passo 3: Aguardar Deploy**
- GitHub levará 2-5 minutos para processar
- Você receberá uma notificação quando estiver pronto
- A URL será: **https://sh1w4.github.io/guardflow-saas/**
